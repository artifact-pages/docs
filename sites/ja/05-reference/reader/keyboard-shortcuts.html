キーボードショートカット

macOSでは⌘、WindowsとLinuxではCtrlを使います。どこで効くかもあわせて示します。

サイトの中で使えるキー

サイトを開いている画面で使えます。サイトの一覧（/）で使えるのは⌘ Kだけです。本文検索とContentsのキーは、その機能があるサイトやArtifactでだけ働きます。

キー動作
⌘ K / Ctrl Kパレットを開く（開いていれば閉じる）。サイトの一覧ではサイトのパレットを開く。
⌘ B / Ctrl Bサイドバーの表示を切り替える。
⌘ ⇧ F / Ctrl ⇧ F本文検索の画面を開く、またはその検索欄へ移る。
⌘ ⇧ O / Ctrl ⇧ OContents。狭い画面ではパネルを開閉し、右の列がある画面ではContentsへ移る。
Tab → Enter最初のSkip to contentで本文へ移る。

HTMLのArtifactの中にフォーカスがあるときに効くのは、⌘ K、⌘ ⇧ F、⌘ Bと、一致のナビゲーターを閉じるEscです。⌘ ⇧ OはHTMLの中では効きません。

パレット

キー動作
↑ ↓ / Ctrl K Ctrl J候補を移る。
Enter選んだ候補を開く。日本語入力の確定のEnterでは動かない。
⌘ Enter / Ctrl Enter入力した言葉で本文を検索する（記号なしの入力のとき）。
Tab / Shift Tabパレットの中でフォーカスを回す。
Escパレットを閉じ、開く前の場所へ戻る。

サイドバーの絞り込み

キー動作
Enter入力した言葉で本文検索の画面を開く。
↓最初の候補へ移る。
Esc入力を消す。空ならフォーカスを外す。

本文検索の画面

キー動作
Enter（検索欄）すぐに検索する。失敗のあとなら同じ言葉でやり直す。
↓（検索欄）最初の結果へ移る。
↑ ↓（結果）結果を移る。最初の結果で↑なら検索欄へ戻る。
Esc結果からは検索欄へ戻る。検索欄では言葉を消し、空ならフォーカスを外す。

Artifactの中の一致

キー動作
Enter / Shift Enter一致のナビゲーターにフォーカスがあるとき、次 / 前の一致へ。「前へ」のボタンにフォーカスがあるときは逆になる。閉じるボタンの上のEnterは、ナビゲーターを閉じる。
Esc一致のナビゲーターを閉じる。

フォルダ、一覧、メニュー

場所キー動作
サイドバーのフォルダ→ / ←、Enter開く / 閉じる。Enterでフォルダの画面へ。
Artifactの一覧↑ ↓、Home End行を移る、先頭 / 末尾へ。
ArtifactのメニューP、LPinの切り替え、Copy link（メニューを開いているときだけ）。
各メニュー↑ ↓、Home End、Esc、Space項目を移る、閉じる、リンクを開く。
More actions↓、Tabボタンの上で開く、メニューを閉じる。
