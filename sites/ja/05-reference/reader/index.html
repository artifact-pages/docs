閲覧アプリ：画面と操作

閲覧アプリの各画面に何があり、どう動くかの一覧です。画面の文言は英語なので、ラベルはそのまま書きます。

サイトの一覧（/）

  • 登録されたサイトをカードで並べます。カードには名前、説明、Artifactの数、内容の更新日、トップレベルのフォルダの数が出ます。
  • 並びはサイトの名前の順です。
  • カードの情報は各サイトの小さな概要から読み、サイトのすべてのArtifactの一覧は読みません。

サイトのトップ（/:site）

部分仕様
Overviewサイトの直下のREADME.md、なければindex.md（大文字と小文字は区別しない）。どちらもなければOverviewは出ず、Filesが開きます。直下のindex.htmlやindex.htmはOverviewにならず、FilesのArtifactとして並びます。
Files直下のフォルダとArtifact。Artifactが7つ以上のサイトでは、Recently updatedに新しい順に6件。
Previewsそのサイトのプレビューの一覧。PRプレビューと、手動で作ったプレビュー（Manual preview）が並ぶ。
検索どの画面にもサイトを検索する入口。狭い画面ではSearch this siteのアイコンボタン。

サイドバー

  • Pinnedとフォルダの構造が並びます。フォルダが先、そのあとにファイルで、どちらもファイル名の順です（数字も文字として比べるので、10-xは2-xより前）。
  • フォルダの名前はフォルダの画面へのリンクで、横の矢印は開閉だけを行います。
  • 上部の欄はタイトル、パス、ファイル名での絞り込みで、Enterで本文検索の画面に移ります。
  • 幅が860pxより広い画面では初めから開いています。それ以下では、Artifactやフォルダに移ると閉じます。

フォルダの画面

  • フォルダの中にREADME.md、index.md、index.html、index.htmのどれかがあれば、この順で最初のものを本文として表示します（サイトのトップとは規則が違います）。
  • 本文を表示するフォルダでは、中身が12件を超えると、最初の10件とShow all N itemsを表示します。開いたあとはShow fewerで戻せます。開いた状態は保存されません。本文のないフォルダは、ふつうの一覧として100件ずつ表示します。

Artifactの画面

部分仕様
HTML閲覧アプリと同じオリジンのiframeで表示。
MarkdownCommonMarkとGFM（表、チェックリスト、取り消し線、自動リンク、脚注）、Mermaid（strictモード）。埋め込まれたHTMLは、許可していない要素と属性が取り除かれます。
右の列幅1200px以上では常にあり、上にDetails、下にContents。Markdownでは本文と一緒にDetailsが流れ、Contentsが残ります。HTMLでは右の列だけが別にスクロールします。
狭い画面ContentsとDetailsはボタンで開くパネル。620px以下では、ヘッダーが簡単になり、操作はMore actionsのメニューにまとまります。
ArtifactのメニューPin / Unpin、Copy link、Open source、View history。どれも公開したArtifactやGitは変えません。

Details

  • 名前。Artifactに関係する最後のコミットの作成者（Gitのauthor）。古い形式のデータではコミッター。最初の著者や管理責任者を表すものではありません。
  • アイコン。公開のときにGitHubのアカウントを確かめられた場合だけ表示。表示できないときは名前の頭文字。
  • Updated。Artifactに関係する変更の日付。一覧を作った日時ではありません。
  • 公開元。リポジトリ、ファイルのパス、参照。GitHubのファイルへのリンク。

パレット

  • 空の状態ではPinned、続いてRecently readを並べます（同じArtifactは1回だけ）。
  • 記号なしでArtifact、@でサイト、#で見出し、>でコマンド。全角の記号も同じように働きます。
  • Artifactの候補の下にSearch full text for …が出て、本文検索の画面に渡せます。

本文検索の画面（/:site/_search）

本文検索の結果は、中央の専用の画面に並びます。検索のしかたと結果の並びは「検索の対象と範囲」にあります。

プレビューの画面

部分仕様
サイドバーChanged pagesとAffected by a resource changeに分けた、そのリビジョンのArtifact。公開されたサイトへ戻るリンク。
見出しPreview · PR #N、Preview · manual、または短いSHA。PR番号は、そのリビジョンがPRのグループの最新だと一覧で確かめられた場合だけ。
DetailsPull request、Revision、Built、Path、Format。More detailsにDefault head、Merge base、Included as。
Builtプレビューを作った時刻（ローカルの時刻。ツールチップにUTC）。Artifactを編集した時刻ではありません。
古いリビジョンThis is an older revision of this preview.とOpen the current preview。同じArtifactが最新のリビジョンになければ、グループの一覧へ移ります。プレビューが消えていればPreview unavailable。
保存プレビューのArtifactは、ピン留めや最近読んだArtifactに入りません。
