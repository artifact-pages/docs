コストとパフォーマンス

費用と速さは、公開と閲覧の処理のどこで、何がどれだけ動くかで決まります。このページでは共通の要因と、これまでの計測の結果を、計測の条件とあわせて示します。数字は計測した条件での値で、性能や請求額の保証ではありません。

要点費用と時間を決めるのは、Artifactの数とサイトの一覧の大きさ、公開の回数、キャッシュの削除です。数字はすべて計測した条件でのもので、保証値ではありません。

費用と時間の要因

場面何が動くか
保存公開したArtifact、一覧、検索のデータ、プレビューのリビジョン（保持期間の間）、閲覧アプリのファイル
公開ロックと状態の記録の読み書き、変わったファイルと一覧の書き込み、キャッシュの削除。Artifactが1つ変わっただけでも、サイトのindex.json全体を読み書きします。変更がなければ小さな記録の読み書きだけです
閲覧閲覧アプリ、サイトの一覧、Artifactの取得。キャッシュに当たらなかったリクエストはストレージまで届きます。キャッシュに当たっても、読者への転送の費用がなくなるとは限りません
検索検索のデータのうち、必要な区画だけの取得

キャッシュの設定

対象Cache-Control
閲覧アプリの入口のファイルno-cache, max-age=0, must-revalidate
ハッシュ付きの閲覧アプリのファイルpublic, max-age=31536000, immutable
登録情報、概要、一覧、検索の目次public, max-age=0, s-maxage=60, must-revalidate
公開したArtifactpublic, max-age=0, s-maxage=300, must-revalidate
検索のデータの区画public, max-age=31536000, immutable
内部の記録no-store（読者には返さない）

CDNは一覧を最大60秒、Artifactを最大300秒キャッシュするので、公開の直後はその間、古い内容が返ることがあります。公開のたびに変わったURLのキャッシュを削除して、これを短くしています。

ブラウザでの計測

合成したArtifact（1千から5万件）のサイトを、手元のnginxで配信して計測しました。Apple M4（32 GB）、Chromium 153、3回の中央値です。nginxは圧縮していません。閲覧アプリは計測時点の版で、いまの版での再計測ではありません。

  • 通信を絞った条件（CPU 4倍遅く、往復150 ms、下り1.6 Mbps）では、1千件で13.8秒かかり、5千件以上はindex.jsonの読み込みが20秒の制限を超えて失敗しました。

詳しい条件と、ここに載せていない数値は、製品の計測の報告（英語）にあります。

CLIのメモリ

CLIは公開元をメモリに読み込んで処理します。Mac（arm64、32 GiB）の手元のファイルシステムに公開し、ピーク時のメモリ（RSS）を3回の中央値で測りました。クラウドへのアップロードやGitHubのランナーでは測っていません。2026年10月17日のビルドでの計測で、いまのCLIでの再計測ではありません。条件の詳細は製品のメモリの計測（英語）にあります。

公開元初回 / 変更なし / 差分あり
小さなファイル10,000個（195.3 MiB）749.9 / 236.8 / 783.9 MiB
256 MiBのファイル1つ542.2 / 278.0 / 541.8 MiB
512 MiBのファイル1つ1054.3 / 534.3 / 1055.5 MiB
大きなファイルで合計1000.2 MiB2032.1 / 1023.6 / 2032.7 MiB

大きな公開元では、書き込みを伴う公開で公開元の約2倍、変更なしで約1倍のメモリを使います。文書で示している対応の範囲は、1ファイル512 MiB、1回の公開の合計1 GiBまでです。CLIはこれを超える入力を拒否しないので、ランナーのメモリに注意してください。

費用のモデル

操作の回数を数えるだけの仮の配信先で公開と閲覧を再現し、2026年10月18日の公開価格を当てはめて月額を見積もりました。実際のHTTPのリクエスト数や請求の記録ではありません。プレビュー、登録の反映、閲覧アプリの配置の費用は含めていません。配信先ごとの結果は各ページにあります。

想定は3つです。Sは5サイト（各200ページ）を1日1,000回、Mは30サイト（各2,000ページ）を1日20,000回閲覧します。LはMに5万ページのサイトを1つ加え、1日100,000回閲覧します。

想定Cloudflare（R2）AWS（多めの試算）
S$0.09$4.05
M$1.86$353.67
L$5.93$1,972.66

表の額は、キャッシュに当たらない割合を10%とした月額です。Cloudflareは無料枠を引く前、AWS（S3とCloudFront）は無料枠をこの用途に使える前提の額です。

AWSの額は多めの試算です。読者がArtifactを開くたびに、圧縮していないindex.jsonを取得すると仮定しているためです。この転送がMで約$225、Lで約$1,745を占めます。実際の閲覧アプリは、同じサイトを読んでいる間、一度読み込んだindex.jsonを使い回します。CLI 0.5.0以降は、AWSには圧縮したindex.jsonを置きます。一方、キャッシュの無効化（Mで約$115、Lで約$125）は、この仮定にかかわらずかかります。リクエストの単価は米国・カナダのもので、ほかの地域ではやや高くなります（AWSのページ）。
